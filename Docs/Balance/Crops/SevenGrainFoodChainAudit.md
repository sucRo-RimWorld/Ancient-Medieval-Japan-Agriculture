# AMJGrains 七穀の収穫・加工・食事バランス静的監査

**初回監査:** 2026-10-08。**現行5粉・8料理の静的再監査:** 2026-10-13。  
**状態:** 陸稲の必須加工を本番XMLへ実装。旧・収穫時直接米の比較は履歴値とし、実機・栽培労働・保存中の損失は未検証。新Recipeの数値と未完ゲートは [RicePostHarvestProcessing.md](RicePostHarvestProcessing.md) に記録。

## 結論と監査範囲

七穀の栽培条件だけでなく、**収穫物→一次加工→可食穀粒→（任意の製粉）→食事**までを対象とする。
RimWorldのIngredientValueGetter_Nutrition、workAmount、保存期間、Moodを別々の指標として扱う。
肥沃度・一定温度・有効成長日数の27セルは履歴六穀Fixtureと `Patches/UplandRice.xml` の陸稲値から計算する。
収穫物はすべて等しい栄養を持つと仮定せず、**可食穀粒としての0.05 Nutrition**が明示されている穀物だけを0.05換算する。
Vanilla `RawRice` の栄養・腐敗期間はGrains所有のXMLで変更していないため、ここでは同一と推定せず実ゲームで確認する。

## 2026-10-25 MO小麦一括製粉600の独立数値監査
