# 食品史C：酢と甘葛煎（2026-10-27）

本資料はC年代照合の研究記録。食品やレシピの実装採用を意味しない。

| 食品 | 時期・記録 | 確認範囲 |
|---|---|---|
| 酢 | 平城宮造酒司地区木簡「中酢」、遺構710–756年 | 酢の物品名。「中」は規格の可能性。 |
| 米酢 | 『延喜式』巻40（927年） | 酢一石の原料として米六斗九升、蘖四斗一升、水一石二斗を明記。 |
| 甘葛煎 | 『延喜式』、平安期 | 甘葛を濃縮して保存・輸送する甘味料。原料植物の同定は未確定。 |
| 甘葛と削り氷 | 『枕草子』 | 甘葛を削り氷に添える供食例。 |
