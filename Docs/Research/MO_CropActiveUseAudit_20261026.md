# MO 1.6.2.2 → Agriculture 残存栽培作物の実用用途監査（2026-10-26）

**対象:** ユーザー提供 MO 1.6.2.2 `3219596926.zip` の `1.6/Defs/ThingDefs_Plants/Plants_Cultivated_Farm.xml` 17品目。直接レシピは同 ZIP の `1.6/Defs/RecipeDefs/Recipes_Meals.xml`、`Recipes_Alcoholics.xml`、`Recipes_Grinding.xml`、`Recipes_SpinningWheel.xml`。収穫物の `foodType`・`Nutrition`・食味は `1.6/Defs/ThingDefs_Items/Items_Resource_RawPlant.xml`、`Items_Resource_Ingredients.xml`。Agriculture main の `Patches/MO_*.xml` による除外を突き合わせる。**数値最終ロードや実ゲームの通常CookBillは未試験。** Vanilla・独自穀物・MO外部Modを全件監査した資料ではない。

## 現行の読み方（2026-10-29作者訂正）

この監査のDef・加工経路・除外実装の記録は保持する。ただし、固有用途や既存作物との差別化を先に要求する旧選定基準は、[Designの現行作物選定](../Design.md#crop-selection-current)で更新された。MO作物も中世日本への適合性で選別するため、MOに同役割の作物があることを日本側作物の不採用理由にしない。専用料理0・価値未判定は現状の用途評価であり、文化的な不採用判定ではない。

## 2026-10-26当時の評価基準（履歴）

1. 栽培をプレイに残す根拠は、史実上の存在のみではなく、**生きた用途があり、代替との比較で有意味な役割があるか**。一次加工・特別な料理・副産物・栽培時期・土壌適性・取引・保存などを比べる。単に食品XMLが残る／原料が食べられるだけなら**価値未判定**。
2. 史実の証拠が足りない西洋式菓子や国内ワインを「使い道がないから」と復活させない。歴史配合を知らない代替菓子を捏造しない。
3. **保存互換Def保持と通常栽培可否は別**。栽培不能にしてもセーブの植物・果実・Billを解決するためDefを残すのが既存の除外設計。逆にDefを残すだけでプレイヤー体験が成立するわけではない。
4. 本監査は用途の**ソース上の存在**と**プレイ上の価値**を区別する。個別係数の自動変更や栽培停止の承認ではない。

## 輸入砂糖の孤立と追加商人在庫の停止（2026-10-26作者承認）

`DankPyon_Sugar`を参照する元MO料理11 Bill = Apple Pie3 + Lemon Cake3 + Sweet Pancakes2 + GriffonBerry Pie3。**Agricultureの現在の各除外パッチにより全11の新規料理Billが停止**。サトウキビ→砂糖の製造3 Billも停止しているため、**旧Agriculture商人追加在庫3～6個/市場価値5.0の仕様には、元MO経路での生産的な消費先が確認できない**。交易・コレクション・他Modの直接使用は残り得るが、現在の農業/料理ループへの価値は未確認。

**実装決定（2026-10-26）:** 作者が明示承認したため、Agricultureの`Patches/MO_SugarImportTrade.xml`を削除し、MO貴族ArtPatronへの砂糖3～6個追加を停止する。砂糖Def・市場価値5.0と、既存MO・他Modの一般的な交易生成処理は変更しない。これは「輸入品が歴史上存在しない」「全Modで砂糖が出現しない」という意味ではない。史料のない砂糖饅頭や別料理の代替追加はしない。将来の商人在庫復帰は具体的な使用先が史実・ゲーム上で確定してから別途承認。旧在庫数値は**履歴のみ**。実際の1.6商人Stockは未検証。

## 優先判断と未完了の比較

1. **生産・汎用食材だけ:** ブドウ／ニンジン／カボチャ／和リンゴは、まず年代・地域・庶民食との接続によって選定し、その後に既存作物との栽培・料理・保存の比較を行う。旧方針の「独自の選択理由が無いものから通常播種の停止を検討」は現行基準として撤回。固有性能がないことだけで除外せず、史実上の存在だけで採用も確定しない。
2. **加工チェーンの歴史再評価:** ニンニクのMOチーズスープ、料理用ハーブのMOスパイス→ソーセージ、和リンゴの長期果樹供給、桑の絹、カラムシの麻布は生きたルートがあるかだけでなく、各ルートに古代・中世日本での用途根拠があるか別に判断。根拠なし料理を補充・温存しない。
3. **無用な供給:** 輸入砂糖は上記のとおり**Agriculture独自の追加在庫のみ停止済み**。未特定の料理用ハーブ生産やその他の無用な通常交易・播種は、食材・加工の実効用途を確認した後で個別判断し、プレイヤーに無意味な加工負担や種子在庫を増やさない。
4. **検証:** リムワの実際の一般食事Billが`VegetableOrFruit`と当該アイテムを認識するか、技術・栽培制限後に通常遊びで本当に選びたくなるかをまとめて検証。**数値を先に作らず、経済価値の高低や「使える」を静的Recipe存在だけで合格にしない。**

## 結論

**9/17が栽培可能な状態、8/17は通常播種から外された状態**。9作物中、MO固有の料理／加工による効用を一切持たず汎用食料に限られるものが**4種**（ブドウ、ニンジン、カボチャ、和リンゴ）。ニンニク・料理用ハーブには固有加工が残るが歴史・実用性に未確認事項あり。小麦、カラムシ、桑には加工／養蚕の独立用途がある。輸入砂糖は元MOで有効な料理用途0となっており、**Agriculture追加商人在庫を作者承認で停止済み**。**この棚卸しは除外の許可ではなく、用途比較に進むための現状監査である。**
