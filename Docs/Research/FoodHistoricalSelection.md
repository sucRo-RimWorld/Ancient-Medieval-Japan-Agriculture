# 食品の歴史重要度による一次選定

**状態（2026-10-28）:** 既存史料を再利用し、主要経路と条件・保留・時代外の一次選定を実施。**50評価行（候補8／条件付き候補11／史料不足で保留27／対象外4）**を記録した。これは食品50種類でも全候補の評価完了でもない。原料・工程・親項目・複合枝を含む判断単位であり、採用・実装の承認ではない。

## 評価の範囲と読み方

- [現行ルール](FoodCultureGameplayDesignConstraints.md)①に限定。性能・効率・MOの食事効果・OH・数値・設備・中間素材の独立化・所有Modは判断していない。
- 史料正本は[食品連鎖台帳](FoodProcessingChainAudit.md)、元候補は[候補索引](FoodItemRegister.md)、調査状態は[作業マップ](FoodAuditWorkMap.md)。追加根拠H28-1〜10は[台帳の補足](FoodProcessingChainAudit.md#hist-commoners)に記録。過去Cでの確認を未確認へ戻していない。
- **候補**は庶民生活の基礎として残す系統。**条件付き候補**は、中世庶民の生産・購入・供食・消費との接続を示す根拠があり、記した地域・季節・行事・供給圏に限って残す判断。全国の日常食の認定ではない。**まだ証拠のない「寺院との接点を描く場合」等は選定条件にせず、接続が不足する枝は保留**とする。公的概説・二次紹介も根拠として使うが、その推定・復原と一次記録を区別する。
- **史料不足で保留**は対象を検討し、選定を左右する不足を特定した状態。**未評価**は個別判断にまだ着手していない枝。両者は別であり、どちらも低重要度や不存在を意味しない。
- 「欠けると不自然」は史料にその文言があるという意味ではなく、支持された食生活をAMJで表現するための今回の文化的判断。保持対象は同性能でも残す方針だが、全工程・中間品の独立実装を承認しない。
- 保留行の「欠けると失われる表現」は検証すべき文化的可能性であり、保持の必要性の確定ではない。
- 原料の存在、製法、供食、普及は別。経路の矢印には候補工程も含み、未確認欄で限界を示す。古代記録から中世庶民の普及を導かず、近世の形を遡及しない。

## 文化的保持の中心

飯・粥と米以外の穀食、味噌による汁・調味、塩、酢、煮菜、漬菜、梅干しを中心候補にする。失われるのは単なる料理名ではなく、穀物を煮炊きする生活、菜を添える食膳、発酵による調味、収穫物を漬けて後に利用する経路である。

大豆・小豆は加工先の多さではなく、直接食・発酵・生鮮加工という食べ方の分岐を評価する。豆腐の村落購入、魚介・海藻の供給圏、門前・参詣時の市売り茶などは根拠のある範囲で条件付き保持とする。納豆の冬季贈答や中世の串柿・醤油名の確認は維持するが、庶民との接続が不足するため文化的保持判定は保留。油も中世庶民の食用証拠を要する保留とし、ゲーム上の役割を理由に落としていない。
